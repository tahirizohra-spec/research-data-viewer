# Research Data Visualizer (Tkinter)

This is a Python Tkinter application developed as part of my doctoral research project.

## Features
- Import CSV datasets
- Display descriptive statistics
- Automatically plot a graph
- Export data to JSON (NoSQL format)

## Technologies
- Python
- Tkinter
- Pandas
- Matplotlib

## How to run
1. Install packages:
   pip install pandas matplotlib

2. Run the app:
   python research_data_viewer.py
